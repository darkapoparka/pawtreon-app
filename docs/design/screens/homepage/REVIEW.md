# Homepage visual reference review

Status: active reference direction, not pixel-final implementation approval.

## 2026-09-13 owner direction

The owner selected the latest Pawtreon homepage iteration as the visual reference for the mobile discovery experience. Preserve the overall quality and hierarchy rather than independently redesigning the route.

Reference image: `concepts/mobile-home-reference-2026-09-13.jpg`.

### Keep

- location control at the upper left, compact Pawtreon paw-heart mark centered, account/avatar at the upper right
- a visible inline search field near the top of the first viewport; do not duplicate it with a second standalone search icon
- one quick-filter row directly under search
- compact photo-led seasonal/community campaign banner after the filters
- `Cases near you` immediately after the banner
- animal-led two-column case cards with need badge, title, location, funding progress, responsible organizer and distance
- clean white/neutral chrome, dark ink, restrained teal accent, real-looking animal photography and generous spacing
- no global impact-stat strip such as “animals helped” or “active campaigns” on home; result counts belong to search/results context

### Navigation direction

The current visual reference tests five dock destinations: Cases / Map / Create / Messages / Campaigns. Map is a real discovery mode and should share the same canonical filters as list discovery. Messages is still exploratory product scope: the icon may remain in the visual reference, but private messaging is not automatically accepted into v1 until the coordination/contact workflow, abuse controls and privacy model are explicitly approved. Account remains reachable from the header/avatar.

### Search behavior

On the initial viewport the inline search field is visible. During downward scrolling, do not keep the entire large header pinned. A compact sticky/scroll-up treatment may surface search or location when useful, but must not duplicate controls or consume excessive vertical space.

### Important caveat

The image is design inspiration and hierarchy guidance. Its fictional names, euro amounts, percentages, badges, distance values, campaign text, photographs and organizer identities are not production seed data, verification evidence or payment claims.
